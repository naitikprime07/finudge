# Auto News Blog

A professional automotive news and blog website featuring the latest automotive industry news, electric vehicle updates, and autonomous driving developments.

## 📁 Project Structure

```
site/
├── articles/              # 48 automotive article HTML files
├── assets/
│   ├── css/              # 6 optimized CSS files
│   ├── font/             # Web fonts
│   └── images/           # Article images and assets
├── index.html            # Homepage
├── privacy.html          # Privacy policy
├── terms.html            # Terms of service
├── package.json          # Project configuration
└── vite.config.js        # Build configuration
```

## 🚀 Quick Start

### Development Server
```bash
npm install
npm run dev
```
The site will be available at `http://localhost:5173`

### Production Build
```bash
npm run build
```
Built files will be in the `dist/` folder

### Preview Production Build
```bash
npm run preview
```

## 🛠️ Technology Stack

- **Build Tool:** Vite 7.1.0
- **Type:** Multi-page application (MPA)
- **Content:** Static HTML
- **Styling:** Vanilla CSS with responsive design

## 🔧 Maintenance

### Adding New Articles
1. Create HTML file in `articles/` folder
2. Add article card to `index.html`
3. Update article images in `assets/images/pages/`

### Updating Styles
- Global styles: `assets/css/base__da64db95.css`
- Header styles: `assets/css/header__004405c3.css`
- Content styles: `assets/css/content__004405c3.css`
